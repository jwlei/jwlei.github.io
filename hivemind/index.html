how it works

A simulated team of AI agents, each a node running on its own GPU pod, works through a hard engineering goal. The orchestrator bus hands out work; layer 1 researches and designs, layer 2 builds, layer 3 verifies and ships. Every token costs money.

hover / tap a node
open it up: the neural net at work and the hardware under it
drag a node
drop it into any slot. Neighbours in a column form links: synergies speed work up, clashes slow it down
click a model tag
switch the node to Fable, Opus, Sonnet or Haiku. Cheaper models get more work sent back
human gate
before shipping, the run waits for you: click approve or type approve
click the bus
ask every node for a status update
click a dispatch row
make that task the top priority
command line
type a goal, or help, approve, spawn, pause, model <node> <fable|opus|sonnet|haiku>
scroll · pinch
zoom; drag empty space to pan; 0 resets
